# WordPress Development

This directory contains information about the WordPress implementation of the Sweet Crumb Bakery website.

## Development Environment

- CMS: WordPress
- Local environment: LocalWP
- Theme: Astra
- Editor: Gutenberg

## Implementation Areas

- WordPress configuration.
- Theme customization.
- Page development.
- Plugin integration.
- Custom functionality.
- Website testing.

## Important

The local WordPress installation, database and sensitive configuration files are not stored in this repository.

The repository will contain relevant documentation and custom development files where appropriate.
