Sweet Crumb Bakery Website
Project Requirements Document & README

1. Project Overview
Sweet Crumb Bakery is a local bakery based in Nairobi, Kenya. The business requires a professional online presence where potential customers can discover products, learn about services, view customer testimonials, and submit enquiries.
This project involves designing and developing a responsive WordPress website that supports the bakery's online visibility and customer engagement.

3. Business Problem
The bakery currently lacks a professional website through which customers can:
Discover products and services.
Find business location and contact information.
Submit custom cake orders and enquiries.
Read about the business background and story.
Access key business details online.
The absence of a structured online presence limits the business's ability to reach potential customers and communicate its offerings effectively.

5. Project Objectives
The website aims to achieve the following:
Establish a professional online presence.
Showcase bakery products and services.
Make it easy for customers to contact the business.
Provide a streamlined channel for custom cake enquiries.
Improve local search visibility through SEO.
Build customer confidence through testimonials and FAQs.
Provide a fully responsive experience across mobile, tablet, and desktop devices.

7. Target Audience
The primary target audience includes:
Individuals purchasing cakes for birthdays and celebrations.
Families looking for baked products.
Event planners requiring custom cakes.
Local residents searching for bakeries in Nairobi.
Customers interested in placing enquiries online.

9. Project Scope
The project will include:
WordPress installation and configuration.
Theme installation and customization.
Homepage development.
About Us page.
Products and Services page.
Custom Cake Orders page.
Location page.
Contact page.
Blog section.
Contact and enquiry forms.
Google Maps integration.
Testimonials and FAQ sections.
Basic on-page and local SEO.
Mobile responsiveness.
Performance testing.
Website documentation.

11. Expected Outcomes
At completion, the project should deliver:
A functional WordPress website.
A consistent visual identity.
Working customer enquiry forms.
Clear website navigation.
Mobile-friendly layouts.
Search-engine-friendly page structures.
Technical documentation.
A GitHub repository containing project evidence.

13. Project Limitations
This is a simulated client project. Business details, customer testimonials and products are illustrative and will not represent a real operating bakery.
The initial development will take place in a local WordPress environment. GitHub will be used for source control and project documentation, not as the WordPress PHP hosting environment.

15. Success Criteria
The project will be considered successful when:
All planned pages are developed.
Navigation works correctly.
Enquiry forms pass functional tests.
Google Maps integration works.
The website displays correctly on mobile and desktop.
Basic SEO requirements are implemented.
Performance and accessibility checks are completed.
Project documentation is available in GitHub.
