4. Website Layout
The homepage will follow a structured visual flow consisting of ten key sections:

Header and navigation
Hero section with bakery imagery
Introduction to the bakery
Featured products
Custom cake ordering promotion
Why choose us
Customer testimonials
Frequently asked questions (FAQ)
Location and contact information
Footer
5. Visual Elements
The website will incorporate consistent visual components across all pages:

High-quality bakery photography
Consistent spacing and padding
Rounded or subtly softened buttons
Clean product cards
Simple, cohesive icons
Clear calls to action (CTAs)
6. Responsive Design Strategy
Layouts will adapt across viewports using a mobile-first approach:

Viewport
Layout & Navigation Strategy
Desktop
Horizontal navigation bar, multi-column product layouts, and a wide hero section.
Tablet
Adapted navigation menu, reduced column counts, and flexible image sizing.
Mobile
Compact navigation (hamburger menu), single-column layouts, readable text sizes, touch-friendly buttons, and accessible forms.

WordPress Gutenberg (block editor)

Browser developer tools (for responsive testing and layout inspection)
9. Design Acceptance Criteria
The design will be accepted when:

The colour palette is consistently applied across all components.
Typography is clear and readable on all screen sizes.
All pages maintain consistent styling and spacing.
Images are appropriately optimized for fast web performance.
Layouts adapt smoothly to desktop, tablet, and mobile screen sizes.
Navigation and calls to action are visually distinct and intuitive.
