# Sweet Crumb Bakery
## Website Testing Plan

### 1. Purpose

This document defines the testing procedures that will be used to verify the functionality, usability, responsiveness, security and performance of the Sweet Crumb Bakery website.

### 2. Functional Testing

The following features will be tested:

**Navigation**
- Verify that all navigation links work.
- Confirm that visitors can access all main pages.
- Test the logo's homepage link.

**Contact Form**
- Submit a valid enquiry.
- Test required fields.
- Test invalid email addresses.
- Verify form submission feedback.

**Custom Cake Enquiry Form**
- Submit a sample cake enquiry.
- Verify that all required information is captured.
- Test date and contact fields.

**Google Maps**
- Confirm that the map loads.
- Verify the displayed business location.
- Test map interaction.

### 3. Responsive Testing

Test the website on:

- Desktop.
- Tablet.
- Mobile.

Check:
- Navigation.
- Image scaling.
- Text readability.
- Button accessibility.
- Form usability.
- Horizontal overflow.

### 4. SEO Testing

Verify:
- Page titles.
- Meta descriptions.
- Heading hierarchy.
- Image alternative text.
- Descriptive URLs.
- Location-related content.
- XML sitemap configuration.

### 5. Performance Testing

Evaluate:
- Image optimization.
- Page loading performance.
- Unnecessary plugin usage.
- Browser performance.
- Core Web Vitals where measurable.

### 6. Security Testing

Verify:
- WordPress administrative access.
- Plugin and theme updates.
- Form validation.
- No exposed credentials.
- No sensitive files committed to GitHub.
